# Features

What this repository does today, what is committed, and what is only an idea. The three
headings are not the same promise, and the difference is the point of the file.

## Available

Shipping now, in this release.

- **48 tools across 8 parts of the job**, weighted towards the work that takes time rather than the work that is easy to sell.
- **No growth, reach, or engagement claims anywhere.** Those outcomes are decided by platform ranking, not by any product listed here.
- **Two complete editions.** English and Arabic, same entries, same order, descriptions written in each language rather than translated.
- **Engagement sellers and platform-breaking automation excluded**, because the account they put at risk is the reader's.
- **Every link resolved over HTTP** before release, and pricing and platform labels from the portfolio's shared vocabularies.

## Planned

Committed. These have a decided shape and will land; nothing is listed here to make the
repository look busier than it is.

- **A pass every quarter**, because platform API changes remove features between releases and a description can go stale without the vendor changing anything.
- **Entries for tools the issue tracker asks about**, which is better evidence of a gap than guessing at one.

## Ideas

Not committed, and possibly never. Listed because a contributor may want to argue for one, or
build it. Opening an issue about any of them is welcome.

- **A column for which platforms each tool actually supports.** The most requested field a social list could carry, and the one that goes stale fastest.
- **A note on each vendor's API standing with the major platforms.** Genuinely useful and not observable from outside.
- **A section on social for a team of one.** A real reader sitting between this list and the small-business one, and probably a different repository.

---

Anything absent from all three lists is absent on purpose. See
[CONTRIBUTING.md](CONTRIBUTING.md) for what belongs here and what does not.
